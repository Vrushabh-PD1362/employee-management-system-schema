# Employee Management System — Database Schema Design

## Overview
This project presents a relational database schema for an Employee Management System, designed to manage employee information, organizational hierarchy, roles, compensation, attendance, and HR operations.

## Key Features
- Employee and employment type management
- Department assignments and historical tracking
- Reporting hierarchy and manager history
- Role management with primary-role designation
- Office assignments and location history
- Compensation records with effective dates
- Attendance tracking and leave requests
- Asset allocation and returns
- Performance reviews and review cycles
- Training and certificate tracking
- Compliance documents and employee separations
- Access control groups
- Employee skills and proficiency tracking

## Database Concepts Demonstrated
- Primary keys and foreign keys
- One-to-many and many-to-many relationships
- Junction tables
- Historical data tracking
- Unique constraints
- Relational database normalization

## Project File
- `employee_management_system_schema.md` — Complete schema definitions and relationship cardinalities.

## Purpose
This project demonstrates relational database design skills, including entity identification, relationship modeling, constraint planning, and historical record management.
